# เกมจับผิดภาพ สำหรับ GitHub Pages

ไฟล์นี้เป็นเกมจับผิดภาพแบบ HTML, CSS และ JavaScript ล้วน สามารถอัปโหลดขึ้น GitHub Pages ได้ทันที ไม่ต้องใช้ Backend หรือฐานข้อมูล

## ไฟล์ในโปรเจกต์

- `index.html` หน้าเว็บไซต์หลัก
- `style.css` ไฟล์ตกแต่งหน้าตาเกม
- `game.js` ไฟล์ตั้งค่าด่าน รูปภาพ เวลา และตำแหน่งจุดแตกต่าง
- `assets/` โฟลเดอร์เก็บรูปภาพ

## วิธีแก้รูปภาพ

นำรูปภาพใหม่ไปใส่ในโฟลเดอร์ `assets` แล้วแก้ชื่อไฟล์ใน `game.js`

ตัวอย่าง

```javascript
leftImage: "assets/my-left-image.jpg",
rightImage: "assets/my-right-image.jpg",
```

แนะนำให้ภาพซ้ายและภาพขวามีขนาดเท่ากัน เพื่อให้ตำแหน่งจุดแตกต่างตรงกัน

## วิธีแก้ตำแหน่งจุดจับผิดภาพ

แก้ข้อมูลใน `differences`

```javascript
differences: [
  { x: 25, y: 43, radius: 6 },
  { x: 51, y: 33, radius: 6 }
]
```

ความหมาย

- `x` ตำแหน่งแนวนอน หน่วยเป็นเปอร์เซ็นต์ของภาพ
- `y` ตำแหน่งแนวตั้ง หน่วยเป็นเปอร์เซ็นต์ของภาพ
- `radius` ระยะคลิกที่ยอมรับได้ ยิ่งมากยิ่งกดง่าย

## วิธีหาค่า x และ y

หลังอัปโหลดขึ้น GitHub Pages แล้ว เปิด URL พร้อม `?debug=1`

ตัวอย่าง

```text
https://ชื่อผู้ใช้.github.io/ชื่อโปรเจกต์/?debug=1
```

จากนั้นคลิกตำแหน่งที่ต้องการบนภาพ ระบบจะแสดงค่า `x` และ `y` ด้านล่างเกม และแสดงใน Console ของ Browser

## วิธีอัปโหลดขึ้น GitHub Pages

1. สร้าง Repository ใหม่ใน GitHub
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้เข้า Repository
3. เข้าเมนู `Settings`
4. เลือก `Pages`
5. เลือก Branch เป็น `main`
6. เลือก Folder เป็น `/root`
7. กด Save
8. รอระบบสร้างลิงก์เว็บไซต์

## หมายเหตุ

สามารถเปลี่ยนภาพ `.svg` ตัวอย่างเป็น `.jpg`, `.png` หรือ `.webp` ได้ โดยแก้ชื่อไฟล์ใน `game.js` ให้ตรงกับไฟล์จริง
